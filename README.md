# Audio to Sound GPT connection

#### Description
{**This is my first python project! You can talk into the microphone after you see the listening now printed on the screen. Then, It will automatically convert your sound into text and put it into Doubao, a big model made by TikTok. After a few seconds, the computer will automatically play the output of this request. As we are just getting started, the number of tokens each conversation allows is limited to only 50.**}
